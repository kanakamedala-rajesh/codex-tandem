# Triage labels

| Label             | Meaning                                             |
| ----------------- | --------------------------------------------------- |
| `needs-triage`    | Needs initial evaluation.                           |
| `needs-info`      | Waiting for information.                            |
| `ready-for-agent` | Specified for implementation; check blockers first. |
| `ready-for-human` | Requires human implementation.                      |
| `wontfix`         | Will not be implemented.                            |

Supplementary labels may coexist with a triage label: `help-needed` for assistance
or a decision, `blocked` for an explicitly named blocker, `bug` for incorrect
behavior, `enhancement` or `feature` for functionality, and `documentation` for docs.
Explicit issue relationships are the source of truth for dependencies.
