# Domain docs

Before planning or implementation, read root GLOSSARY.md, relevant docs/adr/ entries
and [planning-decisions.md](planning-decisions.md). For profile switching, also read
[profile-switching-reference.md](profile-switching-reference.md).

Use the approved SRS vocabulary. Keep domain definitions in one root glossary and
consequential decisions in sequential ADR files. Preserve approved architecture;
cite the SRS source when extracting a decision. Surface requirement conflicts before
dependent work relies on a change.
