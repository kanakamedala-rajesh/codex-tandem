## Reproduction

Build and package: `npm run build`, `npm pack --cache .npm-cache --pack-destination
.scratch`, `npm install --cache .npm-cache --prefix .scratch/installed --ignore-scripts
--no-audit --no-fund ./.scratch/codex-tandem-0.1.0.tgz`.

Set `TANDEM_TEST_PACKAGE=.scratch/installed/node_modules/codex-tandem`, then
`node --test test/*.test.mjs` and `npm run typecheck`. On Windows use a resolved
absolute package path. Run terminal qualification with the same installed package
using `tools/qualify-selector.py`; `--windows-deps .scratch/pty` identifies the
isolated pywinpty installation. Set `TANDEM_CASE_ONLY=child-ctrl-c` for the separate
signal transcript. The harness injects one stderr-write failure through a temporary
Node preload solely to exercise cleanup through the actual installed CLI.

Ubuntu commands are wrapped in `wsl -d Ubuntu -- bash -lc` and start with
`source ~/.nvm/nvm.sh`. Neither `Ubuntu-24.04` nor the `ide` container is used.
No native Linux claim or Docker target claim is made by this local behavior slice.
Selector source imports only local metadata and terminal helpers; child spawn
occurs after selection. There is no credential activation, history scan, network
client, report database, profile CRUD or production resume in this slice.
